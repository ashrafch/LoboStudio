# LoboStudio design implementation
1. Leggi `docs/design-system.md`, `docs/project-brief.md` e verifica logo ufficiale prima di modificare la UI.
2. Parti da gerarchia informativa, template di pagina e wireframe mentali desktop/mobile. Non copiare l'aspetto del vecchio Weebly.
3. Usa tokens centralizzati e componenti riutilizzabili, layout responsive, typography scale, whitespace consapevole.
4. Realizza stati normali, hover, focus, active, loading, empty, error e reduced-motion.
5. Usa foto vere autorizzate; niente stock photo presentata come lavoro dello studio.
6. Valida contrasto e tastiera, breakpoint 360/390/768/1024/1440/1920, layout senza overflow. Documenta esiti.
7. Dopo ogni componente importante, controlla render reale nel browser se disponibile; registra difetti e correzioni.
8. Output: componenti, screenshot reali se possibili, tradeoff e test effettuati.
